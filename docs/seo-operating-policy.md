# Global SEO Operating Policy

RP Studio ships a versioned, client-independent SEO operating method in `prstudio-unified-control/contract/seo-operating-policy-v1.json`, loaded by `PRSTUDIO_UC_SEO_Operating_Policy`.

The policy is **global method, not global client configuration**. It defines the research/evidence/benchmark/strategy/execution/verification/iteration process and the PASS/ITERATE quality gate. Brand, visual identity, market, products, competitors, prior decisions, SEO history and evidence remain in the existing `PRSTUDIO_UC_Memory` site scope.

MCP operator instructions contain only a compact conditional activation rule. SEO, organic-search, Search Console/GSC, Ahrefs, Semrush, Screaming Frog, SERP/keyword, indexing/canonical/schema, linking/backlink and SEO-directed content/media work activates the method. Unrelated WooCommerce, orders, database, engineering, maintenance, CSS/UI and purely promotional social work behaves as before.

The implementation adds no MCP tool/action and does not remove or replace any existing tool or capability. The full policy is an internal versioned contract rather than an additional public action; the existing hard-coded MCP resource list is intentionally unchanged to keep this patch independent of the protocol/UI resource surface. A future resource view, if needed for audit discovery, must remain non-authoritative for activation and must not change the public tool surface.
